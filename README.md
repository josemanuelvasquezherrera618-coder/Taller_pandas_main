# Taller práctico: análisis de datos con Pandas

**Nombre:** Jose Manuel Vásquez Herrera

## Negocios y respuestas

| Pregunta | Respuesta / Criterio |
| :--- | :--- |
| **1** | Categoría con más ingresos: Suma de la columna `total` agrupada por categoría. |
| **2** | Canal que más vende: Mayor monto total de ingresos por canal. |
| **3** | Clientes VIP vs Regulares: Comparación de promedios de gasto por cliente único. |
| **4** | Método de pago más usado: Conteo de frecuencia de `metodo_pago`. |
| **5** | Top 5 clientes: Clientes con mayor cantidad de ventas ordenados descendentemente. |
